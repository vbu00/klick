**Что нового**

Основа — kl!ck 0.4.1 из [vbu00/klick](https://github.com/vbu00/klick) (HWID для панелей с лимитом устройств,
Kill Switch для программ после обновления, импорт sing-box, Xray, WireGuard/AmneziaWG, SIP008 и Outline),
плюс исправления этой сборки:

- **VPN больше не «переподключается» сам.** Одна неудачная проверка сервера (на AmneziaWG такое бывает и у
  живого сервера) больше ничего не трогает: kl!ck молча перепроверяет, и только если сервера нет 20 секунд,
  переподключает серверы, а «Сервер не отвечает» скажет через 45 секунд. Ядро ради проверки больше не
  перезапускается — прямые соединения (сайты не через VPN) не рвутся. Без сети (сон, выключенный Wi-Fi)
  kl!ck ждёт, а не переподключается; на Windows после сна связь проверяется сразу.
- **Смена сети на Windows** — только когда меняется выход в интернет, а не на каждое событие адаптеров
  (Hyper-V, WSL, свой TUN).
- **Обновление подписки по расписанию** больше не обрывает соединения через VPN.
- **Ядро mihomo 1.19.33**: после изменения списков сайты не теряют адреса (ошибка fake-ip в 1.19.31),
  исправления TUN на Windows и macOS, обновление безопасности TLS.
- **Hysteria2**: пароль со спецсимволами, IPv6 с прыжками по портам, `mport`, имя без `#`, Hysteria 1;
  один неверный сервер больше не обнуляет весь список; после сна соединения ждут одно рукопожатие, а не очередь.
- **AmneziaWG 2.0**: H1–H4 диапазонами, S3/S4, I1–I5, PersistentKeepalive больше не теряются при импорте;
  keepalive по умолчанию; адреса сайтов для WireGuard ищутся через туннель.
- **Подписки**: отказ панели (лимит устройств, срок вышел, квота) и пустой список больше не стирают рабочие
  серверы — kl!ck показывает причину; объявление панели, «Поддержка» и «Страница подписки» — на главном
  экране. Проверено с панелью Mistgate.
- **Проверка задержки** идёт в фоне: «Отключить» и остальные кнопки не ждут её.
- **macOS**: DNS и прокси возвращаются наверняка — и при смене «Размещения» сети, и после сбоя записи,
  и при удалении; перевод часов больше не принимается за пробуждение.
